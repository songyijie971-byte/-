# 实验评估与答辩说明指南

本文档用于配合论文实验章节与答辩展示，统一记录课堂行为识别系统的实验数据、方法边界和演示顺序。

## 1. 方法说明

建议在论文或答辩中固定说明以下 4 点：

- 输入数据：课堂短视频与关键帧截图，覆盖低头、睡觉、举手、转头交谈等典型课堂行为。
- 采样策略：离线分析按固定抽帧步长处理视频，实时监测按推理帧间隔控制频率。
- 行为判定：检测结果先映射为课堂行为，再通过连续帧阈值和告警秒数组成稳定事件。
- 结果边界：专注度评分仅用于课堂状态可视化展示，不直接等同于教学质量评价。

- Precision = 正确次数 / 系统检测次数

## 5. 报告页建议讲法

打开报告页后，按以下顺序讲解：

1. 先说结论：风险等级、专注度评分、风险摘要。
2. 再说证据：稳定告警总数、主导行为、最长持续时长、帧覆盖率、分析耗时。
3. 再说细节：行为统计表、时间线、关键截图、规则快照。
4. 最后说建议：教师建议、系统边界、后续优化方向。

## 6. 推荐答辩流程

1. 登录并完成默认管理员改密。
2. 打开规则配置页，展示规则可在线调整。
3. 进入首页或实时监测页，说明总览、摄像头状态和结果边界。
4. 上传视频，展示任务进度、时间节点和失败上下文。
5. 打开报告页，用结论和证据完成核心演示。
6. 最后切到实验评估页，说明指标、参数取舍、局限性和后续工作。
